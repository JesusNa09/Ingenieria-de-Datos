# Semana 05 SQL para Ingeniería de Datos (Parte 3)

## Objetivo
El objetivo de esta semana es entender que es una relación entre tablas, identificando las claves primarias y foraneas , asi como aprender a utilizar las clausulas inner join, left join, right join y full join ademnas de conocer la operacion cross join, ademas comprender y evitar las duplicaciones causadas por Joins, al termini tambien se aprendera a combinar las clausulas join con la clausula group by, al final se entendera como construir consultas que integran información de varias tablas.


## Temas vistos
- ¿Por qué necesitamos JOIN?
- PRIMARY KEY
- FOREIGN KEY
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- CROSS JOIN
- JOIN + GROUP BY
- Alias para tablas
- Concepto muy importante: duplicación


## Lo que aprendí

- Aprendí para que se tienen que usar y para que sriven los joins
- Aprendí las diferentes clausulas de join, left join, right join, full join, la operacion cross join asi como su sintaxis para usarlas.
- Aprendi que es mejor renombrar las tablas de los joins que utilice para que sea mas facil de leer las consultas complejas.
- Aprendi que debo especificar bien los joins para que no haya duplicidad de datos 
- Aprendi a usar la clausula join en conjunto con la clausula group by
