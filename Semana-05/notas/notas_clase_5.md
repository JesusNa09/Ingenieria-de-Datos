# Notas de la Clase 5


# 1. ¿Por qué necesitamos JOIN?
Entendi que los joins sirve para unir datos o resultados de dos o mas tablas diferentes para poder obtener informacion de esas tablas relacionadas.

# 2.PRIMARY KEY
Entendi que es una campo o campos de una tabla de una base de datos que identifican de forma unica a cada fila o registro

# 3. FOREIGN KEY
Entendi que es una llave primaria en una tabla y una llave secundaria o faranea en otra tabla para relacionar tablas


# 4. INNER JOIN
Aprendi que un inner join es una clausula que combina dos o mas tablas por medio de una o mas columnas y devuelven o recuperan los registros o filas que
tienen en comuna ambas tablas 

# 5. LEFT JOIN
Aprendi que es una clausula que combina dos o mas tablas por medio de una o mas columnas y devuelve o recupera todos los registros o filas de la tabla 
izquierda y todos los registros que coinciden de la tabla derecha

# 6. RIGHT JOIN
Aprendi que es una clausula que combina dos o mas tablas por medio de una o mas columnas y devuelve o recupera todos las filas o registros de la tabla
derecha y todos los registros que coinciden la tabla izquierda

# 7. FULL JOIN
Aprendi que es una clausula que combina dos o mas tablas por medio de una o mas columnas y devuelve o recupera los registros cuando hay coincidencias
en la tabla izquierda o derecha 

# 8. CROSS JOIN
Entendi que es una opereracion que devuelve el producto cartesiano de dos o mas tablas, todas las combinaciones posibles 

# 9. JOIN + GROUP BY
Aprendi que se puede usar la combinacion de esats dos clausulas , primero aplicar una operacion de alguna funcion de agregacion a tu o tus columnas relacionandola
con dos o mas tablas por el join y al final agrupando por cierta columna


# 10. Alias para tablas
Aprendi que los alias se puede usar para renombrar las columnas de las tablas a las cual estas haciendo referencia por medio del join para que en consultas complejas
sea mas facil de leer

# 11. Concepto muy importante: duplicación
Entendi que en los joins tienes que tener cuidado ya que al hacer la relacion de las tablas puedes traer datos de mas o basura porque hay relacion uno a muchos asi
que tienes que especificar bien el join
