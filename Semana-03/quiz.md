# Quiz

¿Qué es SQL?
Sql es un lenguaje de consulta estructurado para la manipulacion , gestion y consulta de base de datos

¿Para qué sirve SELECT?
Select es una instruccion que sirve para seleccionar una o mas columnas de la base de datos

¿Para qué sirve WHERE?
Where es una clausula que sirve como condicion verdadera o falsa de una o mas funciones en una consulta 

Diferencia entre WHERE y ORDER BY.
La diferencia entre las clausulas Where y order by es que where sirve para filtrar resultados en funcion de varias condiciones, mientras que 
order by es una clausula que sirve para organizar los datos o resultados de una tabla en orden ascendente o descendente

¿Qué hace DISTINCT?
Es una clausula que sirve para eliminar registros duplicados , solo pone los registros unicos de una consulta

¿Para qué sirve LIMIT?
Es una clausula que sirve para poner solo ciertos registros dependiendo de el numero que pongas, no trae todos los registros de tu consulta

¿Qué es un alias?
Es solo una forma de renombrar temporalmente tu tabla, columna en la base de datos

Diferencia entre PostgreSQL y Oracle para LIMIT.
La diferencia de la clausula limit entre estas dos sistemas de gestion de base de datos solo es la forma de escribirlos ya que en si 
hacen la misma accion en 
PostgreSql:
Select * from Tabla
Where columnas
Limit 5

Oracle:
Select * from 
Where columnas 
fetch first 5 rows only

¿Qué hace FROM?
Es una clausula que indica de que tablas obtendras la informacion o datos para tu consulta
