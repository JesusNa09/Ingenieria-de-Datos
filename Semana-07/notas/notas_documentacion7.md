# Python

## str
Es un tipo de dato que guarda valores de tipo caracter en Python

## list
Es una estructura de datos que almacena datos estos pueden ser mutables

## dict
Es una estructura de datos que almacena los datos de forma clave valor

## tuple
Es una estructura de datos que almacena los datos y estos no pueden ser mutables o sea no se pueden modificar una vez definidos

## set
Es una estructura de datos que almacena los datos de forma unica estos estan desordenados

## if
La instruccion if es una palabra reservada en python que sirve para evaluar condiciones o preguntas y te regresa la primera que encuentre

## for
La instruccion for sirve para iterar o recorrer los valores de tus secuencias, listas , cadenas dentro de tu bloque de codigo de manera rapieda y eficiente 
sin tanto codigo

## range
Esta funcion de python te permite crear una serie de numeros entre los rangos que tu establezcas como inicio o final 

## funciones
Son bloques de codigo que te permiten realizar tareas especificas y puedes reutilizarlas dentro de tu codigo, ademas son mas faciles de entender y acomodar tu codigo
, ayuda a identificar mas claro los pasos de tu codigo y al trabjar en equipi tener una mejor organizacion 

## archivos
Los archivos en python se usan con frecuencia dentro del codigo para poder manipular los datos y su contenido para ello existen varios metodos como de lectura , escritura
para poder trabajar con los datos y poder guardarlos de nuevo con el tratamiento dado, la direccion y el formato que deseas

## open();
La funcion  open en python te permite abrir los archivos este usa dos argumentos como minimo , primero uno donde esta su nombre edl archivo y la segunda el metodo
de lectura, escritura o de agregacion

## with.
Es una instruccion en python para trabajar con archivos de manera mas eficiente y automatica ya que abre y cierra los archivos con mayor confianza a la hora de transcribir
los datos 

## CSV
Los archivos csv se manejan con mayor frecuencia en la manipulacion de datos ya que las bases de datos trabajan mucho con estos tipos de archivos o solo con el archivo de este
formato, python usa una libreria para este formato para poder trabajar en su apertura , modificacion y gurdado para este formato
