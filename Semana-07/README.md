# Semana 7 — Python básico para Data Engineering

## Objetivo
El objetivo de esta semana es empezar a utilizar Python como herramienta de Ingeniería de Datos, comprendiendo los tipos
de datos que hay en python como str, int, ademas te comprender las estructuras de datos como las listas, diccionarios
y aprender a manipular los datos de los archivos

## Lo que aprendí

- Aprendí porque es importante el lenguaje de python para un Data Engineer
- Aprendi que tipos de datos hay en python y como usarlas a la hora de poner o trabajar con mis valores, variables
- Comprendi el concepto de estructura de datos y algunos que hay como las listas y diccionarios
- Aprendi como se trabajan con los archivos en el lenguaje python para abrir, modificar y guardar archivos
- Aprendi a utilizar instrucciones if, elif,else , for en python para poder trabajar con mas eficiencia los datos
- Aprendi que son , para que sirven y como utilizar las funciones en python 
- Comprendi como se manejan lso errores en python con try except
