# Notas de la Clase 1

# Concepto Ingenieria de Datos
Aprendi que la ingenieria de datos es la disciplina de extraer y crear la infraestructura por donde pasaran los datos de un punto inicial a uno final garantizando que 
los datos esten de manera confiable , escalable y esten listo para su consumo

# Porque Nacio la Ingenieria de Datos
Entendi que nacio porque antes era facil extraer datos de una misma fuente, pero en cuanto fueron creciendo esas fuentes de extracccion de datos se necesito un area encarcada de recabar de varias fuentes esa informacion y su camino o proceso que debian tomar para que estuvieran listos para ser consumidos

# Que hace un Data Engineer
Entendi que es el encargado de extraer informacion de varias fuentes, consumir apis, automatizar procesos, analisar pipelines

# Ciclo de vida de los datos
Entendi que para poder tener los datos ya disponibles para su consumo se necesita una serie de pasos en los que hay fuentes de donde nacen los datos, hay una extraccion de toda esa informacion, hay un tratamiento de esa informacion , hay un almacenamiento donde se guardaran los datos, despues un analisis donde se revisaran los datos a detalle y por ultimo una toma de decisiones a partir de tener los datos 

# Arquitectura moderma

# ETL/ELT
Vi el significado de estas abreviaturas identificanco la diferencia de estos dos procesos de manipulacion de datos en la cual la primera se extraen los datos se transforman y se cargan , en el elt se extraen , cargan y se tranforman los datos viendo que solo se diferencian por el proceso en que etl tranforma y carga datos y elt primero carga y ya ahi en donde esten cargados los datos hace la tranformacion de estos dependiendo de la capacidad del sistema

# Data Warehouse
Entendi que esto signfica almacen de datos y que ahi se guardan datos con historicos de diversas fuentes para un analisis detallado y despues tomar decisiones

# Data Lake
Vi que un data lake es un repositorio centralizado que almacena grandes volumenes de informacion o datos en su formato origen o nativo a gran escala, no entendi bien eso de gran escala , creo que solo por que es mucha la informacion con la que se trabaja

# Data Mart
Aprendi que es un subconjunto o un pezado del amacen de datos que se enfoca en el area comercial 


# Batch vs Streaming
Aprendi la diferencia entre estos procesos de datos en la que en el batch se procesan los datos por lotes o sea cierta cantidad por cierto tiempo y el streaming que trabaja con datos casi en tiempo real
