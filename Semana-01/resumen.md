¿Que es un Data Enginer?
Es la persona encargada de crear la infraestructura los caminos por donde pasaran los datos de una manera 
confiable 

¿Que es ETL?
Es un proceso por el cual se extraeran los datos se transformaran los datos y se cargaran los datos

¿Ques es ELT?
Es un proceso por el cual se extraeran los datos se cargaran los datos y se transformaran los datos

¿Qué es un Data Warehouse?
Es una base de datos o sistema centralizado que integraran datos de diversas fueentes operativas (bases de datos, CRM)para
facilitar el analisis, inteligencia comercial y toma de decisiones

¿Qué es un Data Lake?
Es un repositorio centralizado en donde se cargaran grandes volumenes de informacion en su formato original o nativo a gran escala

¿Qué es un Data Mart?
Es un subconjunto especializado de almacen de datos, para un area especialida de comercio como ventas , marketing

¿Qué es Batch?
Es un proceso en el cual la informacion o los datos se procesaran por lotes , o sea en un determinado tiempo una cantidad de informacion  

¿Que es Streaming?
Es un proceso por el cual los datos se procesan en tiempo real

¿Cuál es la función de un Data Analyst?
La funcion de Data Analyst es crear reportes a partir de un analisis de datos proporcionados para ver los resultados de las empresas

¿Qué hace un Data Scientist?
Este se encarga de hacer predicciones a partir de los datos que se les proporcionen para futuras desiciones

¿Qué herramientas aprenderemos durante el curso?
Aprenderemos sql, python ,git, pandas, la nube como un data warehouse
