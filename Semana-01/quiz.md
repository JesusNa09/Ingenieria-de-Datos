¿Cuál es el objetivo principal de un Data Engineer?
Su objetivo principal es crear la infraestructura o canales por donde pasaran los datos de un punto inicial a un punto final de manera viable y confiable

¿Cuál es la diferencia entre ETL y ELT?
Los dos son procesos para la manipulacion de datos, la diferencia es que el ETL extrae , transforma y carga los datos y el ELT extrae carga los datos primero a diferecia
de Etl y ya dependiendo de donde carga los datos ahi mismo los va transformando

¿Qué es un Data Warehouse?
Es una base de datos o sistema centralizado donde integra datos de diversas fuentes operativas(bases de datos,CRM) para su analisis, inteligencia empresarial y
toma de decisiones

¿Qué es un Data Lake?
Es una repositorio centralizado donde se cargan grandes volumenes de informacion en su formato original o nativo a gran escala

¿Qué es un Data Mart?
Es un subconjunto de alcamen de datos especializado, donde se especializan en la inteligencia comercial

¿Qué diferencia existe entre Batch y Streaming?
Son procesos de datos donde batch proceso los datos por lotes , esto quiere decir que cada determinado tiempo a cierta hora procesa los datos y el Streaming procesa
los datos casi en tiempo real

¿Cuál es la función de un Data Analyst?
La funcion de un Data Analyst es realizar reportes y Dasboards a partir de los pipelines proporcionados para ver los resultados
casi en ese momento como va una empresa o negocio

¿Qué hace un Data Scientist?
Un Data Scientist se encarga de analizar los datos proporcionados a traves de los pipelines y hacer futuras predicciones con esos datos para ver 
que acciones tomara la empresa

¿Qué herramientas aprenderemos durante el curso?
Aprenderemos Sql, python, git, pandas
