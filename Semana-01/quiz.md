¿Cuál es el objetivo principal de un Data Engineer?
Su objetivo principal es crear la infraestructura o canales por donde pasaran los datos de un punto inicial a un punto final, garantizando que los datos sean confiables, escalables y estén disponibles para su consumo

¿Cuál es la diferencia entre ETL y ELT?
Los dos son procesos para la manipulacion de datos, la diferencia es que el ETL extrae , transforma y carga los datos y ELT los datos se cargan primero al Data Warehouse o motor de almacenamiento y posteriormente se transforman utilizando la capacidad de procesamiento del propio sistema.

¿Qué es un Data Warehouse?
Es una base de datos o sistema centralizado donde integra datos historicos de diversas fuentes operativas(bases de datos,CRM) para su analisis, inteligencia empresarial y toma de decisiones

¿Qué es un Data Lake?
Es una repositorio centralizado donde se cargan grandes volumenes de informacion en su formato original o nativo a gran escala

¿Qué es un Data Mart?
Es un subconjunto de alcamen de datos especializado, donde se especializan en la inteligencia comercial

¿Qué diferencia existe entre Batch y Streaming?
Son procesos de datos donde batch proceso los datos por lotes , esto quiere decir que cada determinado tiempo a cierta hora procesa los datos y el Streaming procesa
los datos casi en tiempo real

¿Cuál es la función de un Data Analyst?
La funcion de un Data Analyst es analisar informacion,crear reportes, Dasboards e indicadores proporcionados para ver los resultados
casi en ese momento de como va una empresa o negocio y en apoyo a la toma de decisiones

¿Qué hace un Data Scientist?
Un Data Scientist se encarga de analizar los datos proporcionados a traves de los pipelines y hacer futuras predicciones con esos datos para ver 
que acciones tomara la empresa a partir de la construccion de modelos estadísticos y de Machine Learning.
