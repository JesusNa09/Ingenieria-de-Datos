# Semana 04 SQL para Ingeniería de Datos (Parte 2)

## Objetivo
El objetivo de esta semana es saber como transformar datos y resumirlos para en un futuro se pueda subir a un Data Warehouse o entregar a un equipo de análisis para esto se tendra que saber como agrupar información, realizar calculos agregados, crear indicadores de negocio,clasificación de datos,se tendra que saber como trabajar con fechas en conclusion usar sql como herramienta para construir ETL


## Temas vistos
- Funciones de agregación
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- GROUP BY
- HAVING
- CASE
- Funciones de texto
- UPPER()
- LOWER()
- TRIM()
- LENGTH()
- CONCAT()
- Funciones de fecha
- CURRENT_DATE
- EXTRACT
- AGE 
- TO_CHAR
- DATE_TRUNC


## Lo que aprendí

- Aprendí las funciones de agregación para realizar calculos a ciertos valores y obtener solo uno como resultado.
- Aprendí a trabajar con algunas funciones de texto para manipular datos y poderles dar un tratamiento o cambio a los datos.
- Aprendi a utilizar algunas funciones de fecha utiles para poder trabajar lso datos por ciertas fechas que soliciten .
