# Semana 6 — SQL avanzado para Ingeniería de Datos 

## Objetivo
El objetivo de esta semana es entender qué es una subconsulta y aprender a utilizarlas, tambien aprender a crear CTE mediante WITH asi como a encadenar varios CTE,se
entendera la diferencia entre GROUP BY y Window Functions, se aprenderan a utilizar las funciones ventana  ROW_NUMBER(),RANK(), DENSE_RANK() y se aprendera a utilizar PARTITION BY, tambien se aprendera a crear una vista y poder combinar JOIN + CTE + GROUP BY + Window Functions.

## Lo que aprendí

- Aprendí el concepto de subconsultas su sintaxis y cuando es conviniente usarlas ademas para que sirven
- Aprendí el concepto de cte comun expresion de las tablas , su sintaxis para que sirven cuando es conveniente usarlas y su diferencia con las subconsultas.
- Aprendi a usar los ctes pero con bloques en los que tenga que usar las clausulas group by y tambien como tener varios bloques incluso redundantes de los ctes.
- Aprendi a usar las funciones ventana que son , cuales son como row_number(),rank(),dense_rank() su clausula over y cuando usar cada una de ellas como sus diferencias.
- Aprendi la diferencia entre usar la clasula de group by y las funciones ventanas para ver los resultados de una manera que peuda analizar mejor los datos
- Aprendi que es una vista su sintaxis y para que sirven
