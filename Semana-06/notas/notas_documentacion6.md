# WITH
Aprendi que with es la clausula que se usa para poder realizar los cte o comun expresion de la tabla, es la sintaxis con la que iniciaran los cte, estos hacen mas
facil el entendimiento de las consultas , ademas se pueden combinar con sentencias inserts, delete, update

# Window Functions
Entendi que son calculos analiticos sobre un conjuntos de filas relacionadas con la fila actual, ademas estas siempre utilizan por sintaxis la clausula over

# ROW_NUMBER
Aprendi que es una funcion de ventana que premite realizar o generar un numero consecutivo a tus filas a partir de una columna

# RANK
Aprendi que es una funcion ventana que va a clasificar a apartir de una columna los registros de mayor a menor asignando un numero en caso de haber empates
se salta al siguiente numero 

# DENSE_RANK
Esta clausla hace lo mismo que rank solo que esta asigna el conteo de numeros en orden de mayor o viceversa y en caso de haber numeros empates les asigna el 
mismo numero y no se salta al siguiente sino que va asiganando el consecutivo
