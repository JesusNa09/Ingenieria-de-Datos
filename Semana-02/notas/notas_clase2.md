# Pipeline
Aprendi que un pipeline son una serie de pasos para que los datos lleguen de un punto inicial a un punto final, estos datos deben ser de manera confiable
repetible, escalable , automtizado. Tambien vi unos ejemplos de como debe ir un pipeline

# Arquitectura de datos
Entendi que es un bosquejo o representacion de una organizacion que muestra como se recopila, administra, muestran y utilizan los datos

# OLTP
Singnifica online transaction proceding, que es una base de datos que registra operaciones , algunas caracteristicas que tiene son muchas inserciones, muchas actualizaciones, usuarios

# OLAP
Significa online analytical proceding ,son sistemas de bases de datos complementarios, en olap no se registran operaciones sino que se analizan 

# Data Warehouse
Aprendi que contiene cuatro caracteristicas principales, integracion que ahi reune o concentra los datos, historico que es la parte donde almacena los datos por años
tiene orientacion al negocio que es donde las empresas preguntan la informacion orientado a su negocio y optimizado para la lectura que es donde ven consultas rapidas

# Data Lake 
Entendi que es un gran almacen donde entran archivos de cualquiero formato solo para almacenarse sin hacer nada de tranformacion como csv, json , excel , videos, imagenes

# Lake House
Aprendi que es la combinacion de un Data lake y un data house
