1) Ingenieria de Datos
Disciplina que  diseña y construye sistemas para recolectar, almacenar y transformar datos a gran escala.

2) Data Engineer
Profesional que diseña, construye y mantiene los sistemas y las redes de información para que los datos viajen limpios y seguros desde su origen hasta las manos de los analistas y científicos de datos.

3) ETL
Proceso fundamental de integración de datos que significa Extraer, Transformar y Cargar.

4) ELT
Significa Extraer, Cargar y Transformar. Es un proceso de integración de datos en el que los datos se sacan de una fuente, se guardan sin cambios en un lugar central y luego se adaptan.

5) Data Warehouse
Es un sistema centralizado diseñado para recopilar, integrar y almacenar datos históricos y actuales de múltiples fuentes empresariales. 

6) Data Lake
Es un repositorio centralizado que almacena grandes volúmenes de datos sin procesar en su formato nativo.

7) Data Mart
Es un subconjunto de un almacén de datos (data warehouse) diseñado específicamente para una unidad de negocio, departamento o área temática particular.

8) Batch 
Es un método para acumular, agrupar y procesar grandes volúmenes de datos en bloques programados o intervalos de tiempo fijos, en lugar de hacerlo en tiempo real. 

9) Streaming
Es la captura, procesamiento y análisis continuo de información en tiempo real.

10) python 
Es un lenguaje de programación de alto nivel, versátil y de código abierto.

11) sql
Es un lenguaje estándar diseñado específicamente para gestionar, consultar y manipular información en bases de datos relacionales. 

12) postgresql
Es un sistema de gestión de bases de datos relacionales y orientadas a objetos (ORDBMS) de código abierto. 

13) Oracle
Es un entorno de desarrollo integrado (IDE) gratuito, una interfaz gráfica y una herramienta basada en Java que sirve para administrar y gestionar bases de datos.

14) pandas
Es una biblioteca de Python de código abierto que sirve para analizar y manipular datos de forma fácil y rápida.

15) git
Es un sistema de control de versiones distribuido diseñado para rastrear cambios en archivos y coordinar el trabajo de varias personas en un proyecto.

16) docker
Docker es una plataforma de software que permite empaquetar aplicaciones y todas sus dependencias en contenedores ligeros e independientes. 

17) pyspark
PySpark es la API de Python para Apache Spark, que permite realizar procesamiento de datos distribuido, usar DataFrames y ejecutar consultas con la sintaxis familiar de Python.

18) powerbi
Es una plataforma de análisis empresarial de Microsoft que permite conectar, transformar y visualizar datos de múltiples fuentes.

19) Pipeline
Es una secuencia de procesos automatizados o etapas encadenadas donde el resultado de una fase sirve como entrada para la siguiente.

20) Arquitectura de datos
Es el conjunto de normas, modelos y reglas que definen cómo una organización recopila, almacena, transforma, distribuye y usa la información.

21) OLTP
Es una base de datos que registra operaciones.

22) OLAP
Sistema para manejar base de datos que  analiza grandes datos para tomar decisiones, y ambos trabajan juntos guardando y estudiando la información de un negocio.

23) Lake House
 Es una arquitectura de datos moderna que une lo mejor de dos mundos: la flexibilidad y bajo costo de un lago de datos (data lake) con la estructura, velocidad y transacciones confiables de un almacén de datos (data warehouse)
