# Python


## DataFrame
Es una estructura de datos bidimensional donde puedes ver los datos como tablas con dos ejes x y y 

## Series
Es una estructura de datos unidimensional en la que puedes guardar datos de cualquier tipo como diccionarios, tuplas

## Selection
Esta solamente es una forma de elegir tus columnas del DataFrame desde una columna o varias

## Missing data
Es solo una forma de como tratar datos erroneos, que vengan con valor null o faltantes 

## Operations
Son distintas operaciones con las cuales puedes trabajar con tu DataFrame para obtener estadisticas o trabajar con tus columnas dependiendo de las operaciones 
solicitadas

## read_csv()
Este es solo un metodo en python para poder leer tus archivos con formato csv para poder manipular sus datos, convirtiendo tu archivo csv en un DataFrame

## to_csv()
Es un mentodo para poder guardar tus datos convertidos y manipulados a archivos con fomrato csv y dependiendo de la ruta que le asignes
