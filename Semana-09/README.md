# Semana 9 — Limpieza y transformación de datos con Pandas

## Objetivo
El objetivo de esta semana es aprender a tomar un archivo de datos que contiene problemas y convertirlo en un conjunto de datos más confiable y preparado para análisis o carga en una base de datos, esto con metodos de limpieza y manipulacion de datos detectando valores nulos, detectar registros nulos tarbajar con datos incorrectos,filtrar registros invalidos, trabajar con fechas.

## Temas vistos
- ¿Qué es la limpieza de datos?
- ¿Por qué es importante?
- Detectar valores nulos
- ¿Qué hacer con los valores nulos?
- Detectar registros duplicados
- Limpiar textos
- Corregir tipos de datos
- Trabajar con fechas
- Reemplazar valores incorrectos
- Filtrar registros inválidos
- Ejemplo completo
- ¿Qué significa errors="coerce"?

## Lo que aprendí

- Aprendi que es y porque es importante analizar la limpieza y analisis de datos
- Aprendi metodos para poder detectar los valores nulos de mis datos y eliminarlos
- Aprendi que se tiene que hacer cuando se tiene los valores nulos, no solo eliminarlos
- Aprendi a identificar los valores duplicados de mis archivos con los metodos de pandas
- Aprendi a identificar errores en los textos y los diferentes metodos que se pueden usar desde reemplazar archivos o eliminarlos
- Aprendi a identificar los tipos de datos de mis arhivos y si es necesario modificarlos
- Aprendi a trabajar con fechas desde tranformar columnas con caracteres de fechas a tipo fechas , y poder filtrar los datos por fechas
- Aprendi como es un flujo completo de extraccion , tranformacion y carga de datos un proceso de ETL completo
- Aprendi a utilizar el tipo de error en los dataframe para poder manejar datos que no se pudieron modificarse a numericos poniendoles Nan para poder identificarlos y contabilizarlos despues
