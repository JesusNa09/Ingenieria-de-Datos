# Laboratorio

Nombre del archivo
09laboratorio.py
Objetivo

Crear un programa que lea un CSV con problemas y genere un archivo limpio.

Datos de entrada

Crea un archivo llamado:

ventas_sucias.csv

Con estos datos:

producto,categoria,cantidad,precio,fecha
 Laptop ,Electronica,2,15000,01/08/2026
Mouse,electronica,5,500,02/08/2026
Teclado,Electronica,,800,03/08/2026
Laptop,Electronica,2,15000,01/08/2026
Silla,Muebles,3,-2500,04/08/2026
Monitor,,2,4000,05/08/2026
Actividades
Leer el CSV.
Mostrar los primeros registros.
Mostrar los tipos de datos.
Detectar valores nulos.
Detectar duplicados.
Limpiar espacios en producto.
Estandarizar categoria.
Convertir cantidad y precio a números.
Eliminar registros sin producto.
Eliminar o corregir precios inválidos.
Crear la columna total.
Guardar el resultado como:
ventas_limpias.csv
Pregunta que debes responder en tu README

¿Por qué no debemos eliminar automáticamente todos los valores nulos?
